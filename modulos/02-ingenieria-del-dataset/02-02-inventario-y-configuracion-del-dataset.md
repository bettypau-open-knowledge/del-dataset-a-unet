# 2.2 · Inventario y configuración del dataset

Una vez que conocemos la estructura de un dataset y sabemos cómo localizar sus archivos, el siguiente paso es organizar esa información para facilitar su consulta y utilización durante el proyecto.

En esta sección aprenderemos a construir un **manifest**, un inventario estructurado que registra las imágenes, sus máscaras y algunas de sus características. También exploraremos el uso de **archivos de configuración** para centralizar las rutas del dataset y facilitar su mantenimiento y portabilidad.

Estos recursos nos permitirán trabajar con los datos de manera más organizada y reproducible, evitando tener que explorar nuevamente todos los directorios o modificar las rutas en cada notebook.
