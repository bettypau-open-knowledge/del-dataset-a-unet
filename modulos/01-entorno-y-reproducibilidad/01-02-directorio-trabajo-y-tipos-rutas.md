# 1.2 · Directorio de trabajo y tipos de rutas

Antes de trabajar con archivos desde Python, es importante comprender cómo pueden organizarse los archivos y carpetas dentro de un proyecto y desde qué ubicación se está ejecutando el código.

En esta sección exploraremos una **estructura básica de proyecto** como punto de partida para comprender el directorio de trabajo. Después, utilizaremos **Jupyter** para observar el contexto de ejecución distinguiremos entre **rutas absolutas y relativas** y emplearemos `pathlib` para construir y manejar rutas de forma clara y portable.
