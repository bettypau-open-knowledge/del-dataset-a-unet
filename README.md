# Del dataset a U-Net:

### Taller teórico-práctico de segmentación de imágenes con Deep Learning

De los datos al entrenamiento de una red neuronal para segmentación de imágenes.

</div>

---

## 👋 Bienvenida

Este taller propone un recorrido práctico por las etapas necesarias para
desarrollar un proyecto de **segmentación de imágenes con Deep Learning**.

A lo largo de las sesiones se trabajará desde la organización del entorno
y los datos hasta la construcción, entrenamiento y evaluación de una
arquitectura **U-Net**.

El objetivo no es únicamente ejecutar código, sino comprender **qué ocurre
en cada etapa, por qué se realiza y cómo comprobar que funciona
correctamente**.

---

## 🧭 El recorrido

El taller sigue un flujo de trabajo progresivo:

**Comprender → Predecir → Resolver → Comprobar → Interpretar**

Los conceptos se introducirán mediante explicaciones, ejemplos y ejercicios,
para después integrarlos progresivamente en proyectos completos.

## 🎯 Al finalizar el taller

Se espera que puedas recorrer de manera razonada las principales etapas
de un proyecto de segmentación de imágenes:

- organizar y explorar un dataset;
- preparar imágenes y máscaras;
- construir conjuntos de entrenamiento, validación y prueba;
- comprender la arquitectura U-Net;
- entrenar un modelo de segmentación;
- evaluar sus resultados mediante métricas apropiadas;
- interpretar los resultados obtenidos;
- y organizar código, datos, configuración y resultados de forma reproducible.
