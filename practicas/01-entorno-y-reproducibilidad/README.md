# 🧪 Prácticas · Módulo 1

En esta sección encontrarás las actividades prácticas del [**Módulo 1 · Entorno de desarrollo y reproducibilidad**](../../modulos/01-entorno-y-reproducibilidad/01-entorno-y-reproducibilidad.md).

Las prácticas están organizadas de forma progresiva: primero trabajarás con cada herramienta y concepto por separado y, al final, los integrarás en un mismo flujo de trabajo.

# Entorno y reproducibilidad
---

> ## 🌱 01 · Comandos esenciales de Conda
>
> Practica los comandos esenciales para consultar la instalación de Conda,
> crear y administrar entornos, y gestionar los paquetes instalados.

[Ir a los ejercicios de Conda →](./entorno-y-reproducibilidad/01-comandos_conda.md)

---

> ## 📄 02 · Trabajando con `environment.yml`
>
> Aprende a describir las dependencias de un entorno mediante un archivo
> `environment.yml` y a utilizarlo para crear y actualizar entornos
> reproducibles.

[Ir a los ejercicios de `environment.yml` →](./entorno-y-reproducibilidad/02-trabajando_environment_yml.md)

---

# Directorio de trabajo y tipos de rutas

---

> ## 📓 03 · Introducción a Notebooks en VS Code
>
> Familiarízate con la ejecución de **Jupyter Notebooks en VS Code**, prepara y selecciona el entorno de Python que utilizarás como kernel, y experimenta con la ejecución de celdas, el estado del kernel y el orden de ejecución.

[Ir a la práctica de Notebooks en VS Code →](./directorio-trabajo-y-rutas/03-introduccion-notebooks-vscode.md)

---

> ## 📁 04 · Uso de rutas con `pathlib`
>
> Practica el manejo de directorios y archivos utilizando rutas absolutas, rutas relativas y objetos `Path`.

[Ir a los ejercicios de rutas y `pathlib` →](./directorio-trabajo-y-rutas/04-uso-de-rutas-pathlib.md)

# Git, GitHub, Google Colab y Google Drive

---

> ## 🌱 05 · Introducción a Git
>
> Aprende a inicializar un repositorio local, consultar su estado, registrar cambios mediante commits y utilizar el historial para recuperar versiones anteriores de un archivo.

[Ir a la práctica de Introducción a Git →](./git-colab-drive/05-introduccion-git.md)

---

> ## 🔐 06 · Configuración de la conexión SSH con GitHub
>
> Configura una conexión segura entre tu computadora y GitHub mediante claves SSH, registra tu clave pública y verifica que la autenticación funcione correctamente.

[Ir a la práctica de conexión SSH con GitHub →](./git-colab-drive/06-configuracion-conexion-github.md

---

> ## 🙈 07 · Introducción a `.gitignore`
>
> Aprende a excluir archivos del control de versiones mediante `.gitignore`, conecta tu repositorio local con GitHub y comprueba qué archivos se publican en el repositorio remoto.

[Ir a la práctica de `.gitignore` →](./git-colab-drive/07-introduccion-gitignore.md)

---

> ## ☁️ 08 · Introducción a Google Colab desde VS Code
>
> Conecta un Jupyter Notebook de VS Code con un runtime de Google Colab, identifica dónde se ejecuta el código y distingue entre kernels locales y remotos.

[Ir a la práctica de Google Colab desde VS Code →](./git-colab-drive/08-introduccion-vscode-colab.md)

---

> ## 🔗 09 · Conexión entre Google Colab, GitHub y Google Drive
>
> Integra lo aprendido sobre Git y rutas para clonar un repositorio de GitHub, ejecutar su código en Google Colab y guardar los resultados de forma persistente en Google Drive.

[Ir a la práctica de Colab, GitHub y Drive →](./git-colab-drive/09-conexion-colab-github-drive.md)

---

>
> Pon a prueba los conocimientos adquiridos durante el Módulo 1 mediante un cuestionario interactivo de 10 preguntas. Utiliza un Jupyter Notebook en Google Colab o en un entorno local y responde correctamente todas las preguntas para conseguir que el gato aparezca.

[Ir al reto «¡Encuentra al gato!» →](./10-reto-modulo-1.md)
