# 🧰 Instalación de Git en Windows

Para utilizar **git** en **VS Code**, necesitamos tenerlo instalado en nuestra computadora.

Verifica si lo tienes instalado ejecutando en tu línea de comandos:

```batch
git --version
```

Si el mensaje indica que no se reconoce el comando, debes instalar **git** en tu computadora.

En esta sección se muestran capturas de pantalla para guiarte en la instalación.

## ⬇️ Baja el instalador

[Descarga el instalador de git →](https://git-scm.com/install/windows)

Selecciona la versión que corresponda a la arquitectura de tu computadora (x64 o ARM).

## ⚙️ Instala

Ejecuta el instalador. Se deben seleccionar diferentes opciones en los cuadros de diálogo, sin embargo, la mayor parte se dejan en su opción por default.

## ✅ Verifica la instalación

Ejecuta el siguiente código en tu línea de comandos para verificar la instalación.

```batch
git --version
```
Si **git** se instaló correctamente, el comando te regresará el número de la versión instalada.
